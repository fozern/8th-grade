# Aile Merkezi

Simple family site for upcoming events, cetele (ledger) tracking, and graphs.

Open in Chrome: `index.html`

Live 24/7: https://fozern.github.io/8th-grade/

## Use

- Rename the 3 abla cards by typing on them
- Each abla has her own page
- Add events and ledger rows
- Export / import CSV for Excel
- TR / EN toggle

Data is saved in the browser for now. Everyone using the same phone/computer sees the same numbers. Shared family data across phones can be added next.
